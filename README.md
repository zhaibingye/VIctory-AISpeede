# VIctory：Xbox Series S 模式

本项目只做 Xbox Series S（XSS）模式。目标是在配备 16 GB RAM、6 GB 显存独立显卡的 Windows PC 上进入可实际操控的游戏场景，且画面和操作正确。能启动或进入菜单不算通过。**目前尚未验收。**

在画面和操作正确的前提下，尽量降低 RAM 占用、显存占用和内存带宽消耗。靠反复搬运数据来省空间、反而造成卡顿，不算优化。架构和技术栈不限。

源码从 [fxceless/victory-fork](https://github.com/fxceless/victory-fork) 的提交 [`6b3ce6ce54288df514585caa6880f91468c8bc54`](https://github.com/fxceless/victory-fork/commit/6b3ce6ce54288df514585caa6880f91468c8bc54) 起步，感谢 [VIctory](https://github.com/Marvisak/VIctory)、[VIctory-NVIDIA](https://github.com/trustno1-coder/VIctory-NVIDIA) 和各分支的贡献者。[Xenia](https://github.com/xenia-project/xenia) 只作思路参考，不合用就不用，也不是项目依赖。
